# 模态弹窗关闭按钮

## 需求

同步设置、通用设置、导入导出、备份、更新等全屏模态弹窗都应在右上角提供明确的关闭按钮，避免用户只能寻找底部按钮或点击遮罩。

## 实现

- 11 个原本缺少入口的全屏模态弹窗统一使用 `dialog-close-button`；历史记录保留已有的右上角关闭按钮。
- 复制、通用设置、同步测试、导入导出、备份和更新检查等不可安全中断的忙碌状态会禁用关闭按钮，规则与原有遮罩关闭条件一致。
- 关闭按钮提供独立的无障碍标签、键盘焦点反馈以及浅色和深色主题样式。
- 编辑器属性选择器等局部浮层不归入全屏模态弹窗，不添加右上角关闭按钮。

## 代码位置

- 弹窗模板：`src/App.vue`
- 通用关闭按钮样式：`src/style.css`
- 回归测试：`tests/note-tabs.test.cjs`
