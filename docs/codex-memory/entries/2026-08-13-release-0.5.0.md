# 桌面版 0.5.0 发布

## 发布范围

0.5.0 集中发布同步中心、冲突处理、附件管理与完整性修复、便携备份、Base64 资源迁移，以及相关桌面界面优化。

## 版本与验证

- `package.json`、`package-lock.json` 和应用 `Info.plist` 统一为 `0.5.0`。
- 发布前运行完整 Node.js 测试、TypeScript 类型检查和 Vite 生产构建。
- 生成并核对 `release/mac-arm64/心悦笔记.app` 免安装应用。

## 分发说明

当前构建未配置 Apple Developer 签名和公证。首次打开时如被 macOS 拦截，需要在“系统设置 → 隐私与安全性”中允许打开。
