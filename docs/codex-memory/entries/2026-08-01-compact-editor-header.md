# 紧凑编辑器头部

## 需求

原文件夹与标签属性独占一行，占用较多正文显示空间。将属性移动到标题右侧，并压缩 Markdown 工具栏高度。

## 实现

- 标题、文件夹、标签、保存状态、保存按钮和历史记录合并到同一弹性布局中。
- 宽窗口单行显示；窗口宽度不超过 1120px 时，文件夹和标签自动落到第二行，避免标题和操作按钮被挤压。
- 标题区域上下内边距缩小，标题字号从 24px 调整为 22px。
- Milkdown 工具栏高度从 66px 调整为 54px，操作按钮从 58px 调整为 46px，同时收紧图标、文字和分隔线间距。
- 文件夹与标签选择、保存及历史记录继续复用原有行为，不修改数据逻辑。

## 代码位置

- 标题与属性结构：`src/App.vue`
- 紧凑布局及响应式样式：`src/style.css`
- 回归测试：`tests/note-tabs.test.cjs`
