# 2026-08-20：撤销与重做按钮状态

## 问题

桌面端工具栏的撤销和重做是自定义按钮，创建后未读取 ProseMirror history 状态，因此没有历史记录时仍保持常亮。

## 实现

- 使用 `undoDepth`、`redoDepth` 判断当前编辑器状态是否存在可执行历史。
- 正文更新、跨文档 history 重置以及 Crepe 顶栏重绘后同步按钮的原生 `disabled` 属性。
- 预览或只读模式仍优先禁用按钮，禁用视觉沿用工具栏统一主题样式。

## 验证

- E2E 覆盖切换笔记后禁用、编辑后启用撤销、撤销后启用重做。
- 编辑器静态回归测试固定 history API 和更新入口。
