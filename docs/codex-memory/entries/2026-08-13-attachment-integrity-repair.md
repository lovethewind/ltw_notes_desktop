# 附件完整性检查与修复

## 需求

附件管理中心需要识别本地文件缺失或内容损坏，并尽量一键恢复，避免清理、迁移或磁盘异常后正文资源不可用。

## 实现

- 按附件记录的 SHA-256 校验本地文件，分别统计文件缺失和校验异常。
- 有远程地址的缺失或损坏附件会重新下载，并在哈希匹配后原子替换本地文件。
- 本地完整但尚未上传的附件会继续上传；单项失败不会中断后续附件处理。
- 附件管理中心新增“校验异常”统计、筛选项和“检查并修复”按钮，并展示修复数量与失败摘要。

## 验证

- 覆盖健康、缺失、损坏、待上传和部分失败继续执行的回归测试。
- 验证桌面端宽屏和窄屏布局，修复操作提供加载及结果反馈。
