# 退出前保存握手

## 需求

自动保存仍直接写入本地 SQLite，不增加独立草稿缓存；用户退出桌面应用时必须先确保当前笔记的最新草稿已经落库。

## 实现

- 主进程在 `before-quit` 阶段阻止首次退出，并向主窗口发送保存请求。
- 渲染进程等待正在执行的保存，强制提交防抖队列中的最新草稿，并确认内存笔记与草稿一致。
- 保存成功后主进程再次退出，此时才关闭数据库；保存失败或 10 秒超时会取消退出、恢复主窗口并显示错误。
- 保留原有 1.5 秒自动保存间隔，不引入第二份草稿数据。

## 验证

`tests/quit-save-coordinator.test.cjs` 覆盖首次拦截、重复退出、成功放行、失败取消、超时取消以及三端 IPC 接线。
