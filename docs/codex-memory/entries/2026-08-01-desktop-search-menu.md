# 桌面搜索菜单

## 需求

在 macOS 顶部应用菜单中显式展示搜索能力，避免用户不知道应用支持搜索。

## 实现

- 在“编辑”和“显示”之间增加“搜索”顶级菜单。
- 提供“搜索全部笔记…”“快速打开…”和“在当前笔记中查找”三个入口。
- 全库搜索沿用 `Cmd/Ctrl+K`，当前笔记查找沿用 `Cmd/Ctrl+F`；快速打开快捷键可在通用设置中自定义，因此菜单不写死快捷键。
- 菜单通过预加载事件桥接调用现有页面函数，不新增重复搜索逻辑。
