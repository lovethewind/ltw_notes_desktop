# 桌面版 0.4.0 发布

## 发布范围

0.4.0 集中发布复制笔记、浏览器式标签页、ZIP 导入、弹窗与编辑区布局优化，以及同步竞态和大正文性能修复。

## 版本与验证

- `package.json`、`package-lock.json` 和应用 `Info.plist` 必须统一为 `0.4.0`。
- 运行完整 Node.js 测试、TypeScript 类型检查和 Vite 生产构建。
- 生成并核对 `release/mac-arm64/心悦笔记.app` 免安装应用。
- 生成并核对 `release/心悦笔记-0.4.0-arm64.dmg` 安装包。

## 分发说明

当前构建未配置 Apple Developer 签名和公证。首次打开时如被 macOS 拦截，需要在“系统设置 → 隐私与安全性”中允许打开。
