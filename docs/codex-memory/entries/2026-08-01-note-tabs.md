# 笔记标签页

## 需求

编辑区顶部像浏览器一样展示多个笔记标签。普通点击侧栏笔记时在当前标签打开；只有通过笔记右键菜单选择“在新标签页打开”才新增标签。

## 实现约定

- 已经打开的笔记不重复创建标签，而是激活原标签。
- 切换标签继续复用现有 `selectNote` 流程，先保存当前草稿，再加载目标笔记。
- 关闭当前标签后优先选择右侧相邻标签，没有右侧时选择左侧；最后一个标签关闭后清空编辑区。
- 笔记被删除或从工作区移除时，对应标签自动清理。
- 标签右键菜单支持关闭当前标签、关闭其他标签和关闭右侧标签，批量关闭同样遵循草稿保存与相邻切换规则。
- 标签栏按实际宽度计算可见数量；空间不足时将多余标签放进右侧下拉栏，并保证当前标签始终可见。下拉栏内可以切换或直接关闭标签。
- 标签状态仅保留在当前应用会话中；暂不持久化、不支持拖动排序、固定标签或每标签独立滚动位置。

## 代码位置

- 标签状态规则：`src/utils/note-tabs.ts`
- 页面接入与交互：`src/App.vue`
- 标签栏样式：`src/style.css`
- 回归测试：`tests/note-tabs.test.cjs`
