# 正文图片复制地址

## 需求

正文图片右键原先没有响应，需要能够直接复制图片在当前笔记中使用的地址。

## 原因

Markdown 编辑器只监听了普通链接点击，没有监听图片 `contextmenu`。Milkdown 在图片被选中后还会用 `.image-wrapper` 覆盖图片，右键事件不一定直接落在 `<img>` 上。

## 实现

- 图片或其 `.image-wrapper` 上右键时显示“复制图片地址”。
- 复制 `<img>` 当前使用的 `src`：HTTP(S)、Base64 `data:` 和本地 `xinyue-asset://` 地址均支持。
- 本地协议地址复制后提示仅本应用可用。
- 菜单通过 `Teleport` 挂载到 `body`，按实际尺寸限制在视口内；点击空白、滚动、复制完成或按 Esc 关闭。

## 验证

- 静态回归测试覆盖事件注册、图片包装层、剪贴板调用和卸载清理。
- 浏览器实测覆盖包装层右键、视口边界、复制内容、复制后关闭和 Esc 关闭。
