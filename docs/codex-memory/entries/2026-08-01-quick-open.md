# 全库快速打开

## 需求

在心悦笔记前台通过快捷键快速定位任意笔记，不注册系统全局快捷键，避免与其他应用争抢快捷键。

## 实现

- 默认快捷键为 `CommandOrControl+O`，通过 `localStorage` 的 `notes-quick-open-shortcut` 保存，并可在通用设置修改。
- 搜索范围覆盖笔记标题、Markdown 正文、标签名称和完整文件夹路径。
- 空关键词按更新时间展示最近笔记；有关键词时优先级为标题、标签、文件夹、正文。
- 面板支持上下方向键切换、Enter 打开、Esc 关闭，鼠标悬停同步当前选中项。
- 方向键修改选中项后，通过 `scrollIntoView({ block: 'nearest' })` 自动滚动结果容器，避免选中项移出可视区域。
- 快速打开记录正文是否命中；正文命中时切换笔记后自动打开笔记内查找、定位并高亮首个结果，标题/标签/文件夹命中只打开笔记。
- 成功使用的搜索词按最近顺序去重保存 8 条，空搜索时可一键复用；进入笔记后保留关键词并支持 Enter/Shift+Enter 前后切换。
- 跳转复用既有 `selectNote`，不修改该高风险核心函数，避免影响同步、删除和恢复流程。
