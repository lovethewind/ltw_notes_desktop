# 复制笔记

## 需求

使用普通笔记复制满足轻量模板场景。复制时允许选择目标位置，并默认选中原笔记所在位置。

## 实现

- 非回收站笔记的右键菜单增加“复制到…”入口。
- 复制窗口可修改副本名称，并列出“未分类”和现有文件夹；打开时默认使用“原标题 副本”并选中原笔记位置。
- 副本标题追加“副本”，复制正文和标签；不复制历史版本、置顶状态和删除状态。
- 附件不重复创建物理文件，副本正文继续引用已有资源。
- 复制前提交当前编辑草稿，复制成功后展开目标文件夹并打开副本。
