# 桌面端界面层级与可读性优化

## 需求

桌面端功能已经较完整，但宽屏截图中顶部操作层级偏多，云端状态与“拉取最新”入口语义重复，自动保存旁仍展示显式保存按钮，代码块及侧栏摘要对比度偏低，宽屏空间利用不足。

## 实现

- 将云端状态和立即同步合并为主按钮，右侧保留独立同步设置按钮；未配置时主按钮仍会打开同步设置。
- 导入导出改为带提示的图标按钮，移除长期占位的 SQLite 本地库文本。
- 移除编辑器头部显式保存按钮，保留自动保存状态、Cmd/Ctrl+S、切换前落盘及历史记录入口。
- 编辑工具栏由 54/46px 压缩到 48/40px，并提高标签文字可读性。
- 加强浅色和深色代码块的正文、行号、活动行与边界对比度。
- 侧栏摘要和日期字号各提升一级；1600px 以上窗口扩大侧栏、正文画布和大纲宽度。

## 约束

`saveDraft` 影响分析为 CRITICAL，本次未修改其函数或保存调用链，只调整模板入口。同步仍复用 `pullLatestData → runSync → refreshWorkspace`。

## 验证

新增 `tests/ui-polish.test.cjs`，覆盖同步入口、自动保存头部、代码块可读性和宽屏规则；同步更新紧凑工具栏静态断言。

## 代码语言菜单裁切回归

代码块视觉优化曾在 `.milkdown-code-block` 上设置 `overflow: hidden`，导致内部绝对定位的语言选择浮层被代码块边界裁切。外层已恢复为 `overflow: visible`，保留边框和圆角样式，并增加对应回归断言。

## 深色文件夹选择器分隔线回归

文件夹选择弹层的分隔线由 `background` 绘制，原深色规则误设为 `border-color`，导致夜间模式仍显示浅色横线。深色主题现单独覆盖分隔线背景，并保留标签输入区的边框颜色规则。

## 后续交互优化

- 文件夹选择弹层增加即时搜索、自动聚焦和空结果反馈，完整文件夹选项仍供复制、导入等其他弹窗复用。
- 同步按钮的无障碍名称和提示明确为“同步全部笔记”，有待同步内容时同时显示数量。
- 保存失败状态改为可点击重试，但继续复用既有 `saveDraft`，未修改其 CRITICAL 保存链路。
- 属性弹层颜色收敛到主题变量，并按视口限制宽高；代码语言列表限制为视口高度的 42%，展开时提高代码块层级。
- 代码块复制反馈改为“代码已复制”，避免与其他复制操作混淆。

## 资源右键菜单视口裁切回归

此前的视口限制只覆盖属性弹层和代码语言菜单，侧栏资源右键菜单仍用固定数值猜测菜单高度；笔记菜单项增多后，靠近窗口底部打开会被裁切。资源菜单与标签页菜单现统一在渲染后读取真实宽高，再将位置收回视口；同时限制菜单宽高，极小窗口使用内部滚动。

## 属性搜索框高度与描边回归

标签和文件夹搜索框位于 `.properties-row` 内，通用输入框的固定高度与聚焦描边会覆盖弹层内的局部样式，造成标签输入区域高度不一致并出现内层横线。两个搜索框现共用 34px 无边框容器，输入框完整填充容器，并显式清除普通态和聚焦态的边框、阴影。
