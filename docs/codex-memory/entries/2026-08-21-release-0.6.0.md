# 桌面版 0.6.0 发布

## 发布范围

0.6.0 集中发布本地工作区会话与固定标签、树形批量管理、高级搜索、工作区正文按需加载、渲染首包和功能模块拆分，以及同步、关窗、撤销历史和冲突展示稳定性修复。

## 版本与验证

- `package.json`、`package-lock.json` 和应用 `Info.plist` 统一为 `0.6.0`。
- 发布前运行完整 Node.js 测试、Electron E2E、TypeScript 类型检查和 Vite 生产构建。
- 生成并核对 `release/mac-arm64/心悦笔记.app` 免安装应用。

## 分发说明

当前构建未配置 Apple Developer 签名和公证。首次打开时如被 macOS 拦截，需要在“系统设置 → 隐私与安全性”中允许打开。
