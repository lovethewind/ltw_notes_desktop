# 清空回收站同步防复活

## 需求 / 现象

桌面端清空回收站后，如果先前启动的自动同步随后返回，已永久删除的笔记可能再次出现。

## 原因

同步请求发出后到响应返回前，用户可能继续产生本地变更。旧实现应用同步结果时会笼统清空 outbox，因此会误删这段时间新生成的永久删除墓碑；随后旧云端快照又会把对应笔记写回本地，下一轮同步也已无法继续删除云端数据。

## 处理

- 同步批次记录实际发送的 outbox ID，响应成功后只确认这些记录。
- 应用云端快照前读取仍待发送的删除墓碑，跳过对应的文件夹、标签和笔记，防止旧快照覆盖本地永久删除。
- 增加“同步期间清空回收站”的数据库回归测试，确认笔记不会复活且删除墓碑会留到下一轮同步。
