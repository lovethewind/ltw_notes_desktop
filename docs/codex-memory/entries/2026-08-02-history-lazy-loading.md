# 历史记录按需加载

## 问题

桌面端打开历史记录弹窗时，会先等待一次完整同步，再从本地数据库读取最多 50 个版本的完整正文。历史正文较大或包含 Base64 图片时，同步、IPC 传输及首个 Markdown 编辑器挂载都会明显延迟弹窗展示。

## 处理

- 历史列表只读取本地数据库，打开弹窗不触发同步；同步仍由本地变化后的防抖任务和 30 秒定时任务负责。
- 列表查询只读取有限长度正文并生成 120 字摘要，不通过 IPC 传输全部历史正文。
- 新增单个历史版本详情读取接口，用户选中版本时才加载完整正文。
- 详情加载完成前展示读取状态，避免用空正文初始化预览编辑器。

## 验证

- 数据库测试覆盖大正文历史列表摘要与详情按需读取。
- 性能回归测试约束历史列表不得等待或触发同步，并校验详情 IPC 和前端懒加载逻辑。
