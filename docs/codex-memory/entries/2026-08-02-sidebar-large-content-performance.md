# 侧边栏大正文展开优化

## 现象

展开包含大正文或 Base64 内嵌图片的文件夹时，桌面端侧边栏会短暂卡顿，而网页版无明显延迟。

## 原因

桌面端在笔记节点挂载时对完整正文执行多轮正则并把完整摘要交给 DOM，同时每个文件夹节点递归扫描文件夹和笔记统计数量。网页版列表则只接收最长 120 字的 `contentPreview`，文件夹数量使用一次性统计映射。

## 处理

- 非搜索状态只处理正文前 480 个字符，列表摘要最多输出 120 字；全文搜索仍保持完整正文匹配。
- 文件夹及父级路径的笔记数量改为一次性计算并向递归节点传递映射。
- 网页后端摘要生成只规范化正文前 480 个字符，避免 `split()` 扫描包含 Base64 的完整正文。
