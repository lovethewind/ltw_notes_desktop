# 快速记录窗口布局

## 关闭与状态提示

- 保存状态消息显示在底栏上方，避免覆盖右下角保存按钮。
- macOS 下 Esc 或保存成功隐藏快速记录窗口时同时隐藏应用，防止主窗口被系统自动带到前台；下次快捷键呼出前调用 `app.show()`。
- 保存成功后立即清空标题、正文与提示并关闭窗口；每次重新呼出也会重置上次的成功或错误提示，避免窗口复用导致旧状态残留。
- 主窗口启动后的延迟更新检查发送 IPC 前必须确认窗口和 `webContents` 未销毁，避免快速关闭应用时触发 `Object has been destroyed`。

## 需求

快速记录窗口应优先突出正文区域。顶部内容需避开 macOS 窗口控制按钮，底部文件夹选择、保存提示和按钮保持紧凑；按 `Esc` 时即使焦点位于正文或输入法中，也应关闭窗口。

## 实现约束

- 顶部使用足够的安全内边距，避免标题区与 macOS 红黄绿按钮拥挤。
- 底部栏使用紧凑字号和控件高度，但保留清晰的点击区域。
- `Esc` 关闭由 Electron 主进程的 `before-input-event` 兜底，不仅依赖渲染层键盘事件。
