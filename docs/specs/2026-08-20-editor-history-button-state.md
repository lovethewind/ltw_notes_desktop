# 编辑器撤销与重做按钮状态规格

## 问题

自定义工具栏的撤销、重做按钮没有读取 ProseMirror history 深度，即使当前笔记没有可执行操作也始终常亮。

## 行为

- `undoDepth` 为 0 时禁用撤销按钮，`redoDepth` 为 0 时禁用重做按钮。
- 正文编辑、撤销、重做、切换笔记和 Crepe 顶栏重绘后都同步按钮状态。
- 禁用使用原生 `disabled` 属性，沿用现有浅色和深色主题置灰样式，并阻止点击。

## 验证

- Electron E2E 验证切换后两者禁用、编辑后撤销启用、撤销后重做启用。
- 静态回归测试固定 history 深度读取和状态同步入口。
