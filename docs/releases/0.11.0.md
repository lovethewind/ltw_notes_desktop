# 心悦笔记 0.11.0

这一版把 AI 助手从一个「问一句、答一句」的输入框，做成了**能连续追问、能读懂你选中的段落、答完还能直接变成笔记**的对话工具；对话本身也会留下来，下次打开同一篇笔记自动接上。编辑器这边补上了**查找替换**，同步完成后还会提醒你哪些本机链接可以转成网页地址。另外修掉一个把外部文件大纲侧栏压成 26×26 的问题。

## AI 笔记助手：可以连起来问

从右上角的 ✨ 按钮打开，或选中一段正文后在气泡里点「问 AI」。

- **追问会带上文**：接着上一轮问，模型能看到最近 6 轮对话（约 6000 字），不用每次把前提重说一遍。
- **边想边出字**：回答流式显示，长回答不用干等一大段空白。
- **随时收手**：生成不满意可以立刻**停止**；停完还能对最后一轮**重新生成**，答案就地替换，不会多出一个重复气泡。
- **范围三档**：当前笔记 / 当前文件夹 / 全部笔记，右下角会提示当前档位实际在哪儿找。
- **长笔记有预算**：当前笔记最多取 16000 字，超出的来源卡片会标出「只取了前 N 字」，不会让你以为模型看了全文。

## 引用能对上原文

- 回答里的 `[S1]` `[S2]` 是**可点的来源标记**，点一下直接跳到那篇笔记。
- 跳过去会**滚到正文里命中的那一段**，而不是停在笔记顶部；只滚动、不选中文字，不会把你下一次输入覆盖掉。
- 回答如果漏标来源，只会在气泡下方提示「本条未标注来源」，不会整条作废。
- 回答末尾的来源列表同样可点，历史对话里的来源笔记标签也能点。

## 回答可以直接变成笔记

回答气泡上方有四个动作：重新生成、复制、**插入到当前笔记**、**存为新笔记**。

- 插入是在光标处追加，不动你已有的内容；光标正卡在段落中间时会先把段落断开再插，不会把一句话劈成两半。
- 存为新笔记会**跟随当前笔记所在的文件夹**保存，并自动用你的提问当标题。
- 落地的 Markdown 里会保留 `[S1]` 标记，末尾用分隔线接「参考来源」，每条都是指向原笔记的链接 —— 插进正文就是可点的双链。

## 对话会被记住

- 对话保存在本机（最近 50 条 / 30 天），**不参与同步**，只留在发起的那台设备上。
- **记住是在哪篇笔记下问的**：历史列表的副行会标出「📄 笔记标题 · 时间 · N 轮」，点笔记标题直接跳过去；那篇笔记被删了会显示「笔记已删除」，问答本身不丢。
- **自动续接**：打开某一篇有历史的笔记再点开助手，会自动载入最近一条对话，顶部横幅提示「已载入《XX》的对话」，右边可以一键「开始新对话」。
- 历史支持**搜索**（标题或任意一轮提问里的词）、**行内改名**（回车提交、Esc 取消、最多 80 字）、**置顶**。改名和置顶都不会打乱原来的时间顺序；置顶的对话既不会被 30 天清理掉，也不占 50 条的名额。

## 选中一段就能问

- 选中正文后，气泡工具条末尾多了 **✦ 问 AI**：把这半句话直接带进面板，作为最优先的资料（标记为 `[S1] 选中片段`）。
- 带进去的片段可以一键移除，改成检索笔记。

## 查找与替换

- 查找条按 `⌘⌥F` 展开替换行，输入替换词后 `⌘Enter` **全部替换**。
- 替换是**一次性完成**的：按一次撤销就把整批替换整体退回，不会撤一步只退一处。
- 关闭查找会收起替换行；切换笔记或切换文件会清空替换词（避免带着上一篇的替换目标误点「全部」）。
- 替换内容按**纯文本**写入 —— 替换成 `**粗**` 得到的就是这串字符，不会被解析成加粗。

## 同步之后：提示哪些链接可以转了

最常见的残留是「先插链接、目标笔记后同步」：那时候目标还没有网页地址，链接落成本机地址，之后同步也不会改写正文，于是在网页端既认不出、又会被带去不存在的域名。

现在同步完成后会看一眼：如果本轮有笔记第一次拿到网页地址，且正文里存在这类链接，就提示「N 篇笔记里的 M 条本机地址可以转成网页地址」，点「去转换」进入数据管理的既有预览流程。**只提示、不改写**，改不改由你确认。

## 修复

- **外部文件的大纲侧栏被压成 26×26**：模式条上的大纲按钮与侧栏此前共用同一个类名，两边互相把对方撑坏 —— 173 个标题全被裁掉。现已拆成两个独立类名，窄窗口下的浮层也改成实色背景，不再透出底下正文。
