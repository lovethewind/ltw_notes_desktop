# 心悦笔记 0.9.0

这次是一轮围绕「编辑器与预览」的集中打磨。正文可以给任意一段文字**单独设置字号**；选中文字会浮出与编辑器同语系的操作气泡；**预览从「只读开关」升级成真正的渲染视图**（表格、公式、嵌入卡片都能正确显示）；链接和图片的交互整体重做，并新增**纯净 Markdown 导出**，把笔记发给别人时不再夹带内部格式；本地 Markdown 文件也支持大纲与复制。

## 正文字号

- 正文支持**行内字号**：选中一段文字直接改字号，只影响选中的部分；光标没有选中内容时改字号，则作为**后续输入的默认字号**。
- 字号档位扩到 **17 档**，取值与钉钉对齐。
- 入口放在编辑器工具栏「一级标题」旁的下拉里，随手可及。
- 原来的「整篇显示缩放」已移除 —— 它与行内字号语义冲突，且会连带影响所有块级元素的排版。
- 标题样式（各级标题的字号、字重、间距）对齐钉钉。

## 选区操作气泡

- 选中文字后浮出的操作气泡重新配色，与编辑器其它浮层统一。
- 气泡内新增**字号下拉**，选中文字后不必再跑回顶部工具栏。
- 修复了气泡的两个可用性问题：点字号图标后下拉一闪即失，以及必须按住鼠标左键气泡才在、一松开就消失。

## 渲染预览

- 预览从「给正文套一层只读样式」改成**独立渲染视图**，边距、字体、行距按阅读排版，不再是编辑器样式的副产物。
- **表格单元格支持块级内容**：单元格里可以放段落、列表、代码块，换行按 Shift+Enter 保留。
- **公式渲染**：`$...$` 与 `$$...$$` 走 KaTeX 渲染成真正的数学公式。
- 新增**笔记嵌入卡片**渲染：预览里能看到嵌入的是哪篇笔记，显示实时标题（笔记改名后不会显示旧名字）。
- 修复预览里**本地图片全部断链**的问题 —— 图片地址被安全清洗误伤，现已放行本应用私有协议，并把这套清洗收敛到唯一入口，三处预览共用。
- 大纲锚点跳转的落点分别按编辑态与预览态校准，跳转后内容不再离顶部太远。

## 链接

- **点击链接文本直接跳转**，不再需要按住 `Command / Ctrl`（此前点下去什么都不发生）。
- 气泡左侧槽位拆成**「打开」与「复制」**两个按钮，主操作带文字标签，一眼看得出。
- 气泡里不再显示那串长长的地址，只留操作按钮。
- 编辑链接改成**锚定在链接上的表单浮层**：可以同时改**标题**（即链接文字）和**地址**，并提供「取消链接」（只摘链接、保留文字）。
- 数据管理面板新增**「本机笔记地址转网页地址」**：扫描全库正文里以本机地址写成的笔记链接，**先给出将影响多少篇、多少条的清单**（并区分因未配置网页地址等原因无法转换的部分），确认后才执行改写，用于清理历史遗留的本地链接、让它们在网页端也能正常打开。

## 图片

- 预览态与编辑态都支持：鼠标悬停图片浮出**操作工具条**（放大查看、复制图片、另存为、在浏览器打开），点击图片进入**全屏查看器**。
- 全屏查看器支持滚轮缩放、拖拽平移、双击回到 1:1、「适应窗口」、`Esc` 关闭，多张图可左右切换；缩放以光标为锚点，不会越缩越偏。
- 修复编辑态下悬停/点击无反应的问题（图片上方盖着一层容器，拦截了指针事件）。
- 修复编辑态右键弹出**两个重叠菜单**的问题。
- 修复全屏查看器右上角的图片计数被窗口交通灯按钮压住的问题。

## 本地 Markdown 文件

- 打开磁盘上的 `.md` 文件可**源码编辑 + 渲染预览**双模式切换，保存时原样写回。
- 支持把本地 Markdown 文件**导入到笔记库**，连文件里引用的本地图片一起搬入（图片转为应用内附件）。
- 本地文件同样接入**大纲侧栏**与**复制 Markdown**（与笔记共用同一个开关记忆）：源码模式下点大纲会滚动并把光标定位到该标题，预览模式下平滑滚动到对应位置；两侧都支持滚动联动高亮当前所在小节。

## 冲突副本对比

- 冲突副本的处理界面新增**文本对比视图**（默认打开）：左右并排、两侧同步滚动、差异行整行高亮，差异中的具体字词再行内标出。
- 可逐处跳转到上一处 / 下一处差异，共有几处差异一目了然。
- 需要整段连贯阅读时，可随时切回原有的富文本视图。

## 界面与模式条

- 顶栏的「预览」按钮下线，改为**常驻模式条**，编辑 / 预览切换随时可见。
- 模式条横跨整个窗口宽度，大纲开关与「复制 Markdown」一并搬上去 —— 预览态下也能随手调出大纲。
- 「专注模式」已移除（与其他模式的收益重叠），顶栏随之清掉了空下来的「更多」菜单。

## 夜间模式

- 修复夜间模式下**各级标题与表格表头文字偏淡**的问题：它们此前沿用浅色主题的深色文字，暗色主题只改了正文、漏了标题，现在统一为亮白色。

## 导出

- 新增**「导出为纯净 Markdown」**：去掉内部元数据、把内部 HTML 写法降级成普通 Markdown（字号只留文字、换行还原成空行、嵌入卡片转成指向该笔记的链接）。
- 围栏代码块内的内容**原样跳过**，不会被误改。
- 原有的「导出当前笔记」保持不变，继续作为**备份 / 迁回本应用**的通道（带元数据，导回来不丢标题、标签、时间）。
- **批量导出**（「导出全部 Markdown」与笔记列表右键「导出所选」）同样走备份格式，导回来不丢标题、标签、时间；从 ZIP 导入时会自动剥掉导出时追加在文件名末尾的 ID 后缀，让标题回到你原本起的名字。
- 数据管理面板的所有入口重新**按用途分成四组**（导入 / 导出 / 备份与恢复 / 工具），卡片去掉常驻描边、改为悬停浮起，一眼看清每个按钮是干什么的。

## 稳定性与工程

- 修复编辑公式时，公式编辑气泡被撑满整个视口的问题（一条全局编辑器样式规则泄漏到了浮层作用域）。
- 修复纯净导出遇到**嵌入卡片**时必定报错的问题（数据层少导出一个方法，属于此前引入的回归）。
- 修复了一条挂了很久的端到端用例不稳定问题（等待策略改为轮询实际状态，不再赌固定延时）。
- 后台 Electron 端到端测试 **45 个用例**全部通过；单元测试 **430 项**通过。

## 已知限制

- 嵌入卡片同步到网页端后，阅读页仍显示为空块、编辑态显示为一段源码文本。数据会完整保留、不会丢失，桌面端不受影响；网页端暂不支持渲染卡片。
- 打开磁盘上的 `.md` 文件时默认进入**源码模式**（外部文件保真优先，应用不会自动改写原文），需要看排版效果请切到预览模式。
