# 心悦笔记 0.10.0

这一版把「笔记与笔记之间」的连接补完整了：**嵌入卡片打通了桌面端与网页端**（网页端插的卡片，桌面端不再是源码；桌面端插的卡片，网页端也能显示成卡片），**历史版本可以逐版对比改动**，`[[` 补全一次给出更多候选和正文摘要，编辑器右键菜单也重新分组收窄。另外修掉一个会连带吞掉正文的行内公式问题。

## 嵌入卡片：桌面端 ↔ 网页端

- **网页端插入的卡片，桌面端能正常显示**。此前这类卡片在桌面端会显示成一行 HTML 源码 —— 0.9.0 只认本机标识，而网页端插入时只能写网页标识。本版两种标识都识别：能取到本机 ID 就用本机 ID，取不到就按网页标识回落取数。
- 桌面端插入卡片时，如果被嵌入的笔记已经同步到网页端，会**一并写上网页标识**，同步后网页端直接显示成卡片。
- **卡片信息三处统一**：编辑态、预览态、「导出为纯净 Markdown」共用同一份摘要与日期算法 —— 同一张卡在哪个模式看都一致（此前换模式看摘要或日期可能对不上）。
- 预览里的嵌入卡片补上**图标与笔记信息**，并且可以**点击或回车直接打开**被嵌入的那篇笔记。
- 数据管理 → 数据修复新增**「嵌入卡片补线上标识」**：给早期创建的卡片补上网页端能识别的标识。执行前先给影响范围 —— 多少张可以补、多少张目标笔记尚未同步到网页端（这部分保持原样）、多少张目标笔记已不存在 —— 确认后才改写。

## 历史版本对比

- 版本抽屉里选中任意一版，可直接切到**「对比改动」**看它相对上一版动了哪里（打开即默认落在这一档）。
- 差异视图与冲突副本对比共用同一套组件：左右并排、两侧同步滚动、差异行整行高亮，差异中的具体字词再行内标出，可逐处跳到上一处 / 下一处。
- 最早的一版没有更早的版本可对比，界面会直接说明，不留一块空白。
- 版式一并调过：弹窗高度、对比卡片间距、档位字号。

## 编辑器右键菜单

- 8 种块类型（正文、一 ~ 三级标题、引用、无序列表、有序列表、代码块）收进**「段落样式」二级菜单**，主菜单不再逐条平铺。
- 子菜单会自己判断翻边：贴到窗口右侧就向左展开、贴到下边缘就向上收，不会被窗口裁掉。

## `[[` 笔记链接补全

- 候选大幅增加：没输入时列出**最近 20 篇**，输入关键词时搜出**50 条**。
- 每条候选补上**正文摘要**，标题相近的笔记也好区分了。
- 修了候选列表的两处可用性问题：用键盘上下移动时选中项不跟随滚动；条目偏长时横向滚动条冒出来。

## 行内公式

- 修复**没选中文字就点「行内公式」**：此前会插入一个空公式节点，屏幕上看不见（像是点了没反应），存到 Markdown 里却是孤零零一个 `$$`；这种行落在行首时会破坏文件结构，重新打开会把后面的正文一并吞掉。现在这种情况只提示、不改动文档；选中文字插入、以及在已有公式上再点一次拆掉，都不受影响。
- 修复**公式气泡点「勾」不收起来**的问题，现在确认即收起。
- 公式气泡的层级抬到顶栏之上（与链接气泡、选区气泡一致），窄窗口下也不再和左侧的块操作手柄挤在同一块地方。

## 打包

- macOS 安装包文件名固定为英文 `xinyue-notes-macos-<版本>-<架构>`，不再随系统语言变化（应用名与 dmg 卷标仍是「心悦笔记」，与更新检查链路此前的期望也对齐了）。
- 补齐 Windows 打包配置（NSIS / x64 + 应用图标），产物名统一为 `xinyue-notes-<系统>-<版本>-<架构>`。

## 稳定性与工程

- 单元测试 **490 项**全部通过；后台 Electron 端到端用例 **50 个**。
- 新增 9 个测试文件（含 3 个端到端）：嵌入卡跨端往返、补标识扫描、卡片点击打开、右键二级菜单、链接补全、历史对比、卡片摘要口径、行内公式守卫。
- 嵌入卡的跨端契约整理成文档（`docs/specs/2026-10-12-note-embed-web-render.md`）：属性顺序、标识回落规则、序列化口径都写在里面，两端照此对齐。

## 已知限制

- **升级顺序：桌面端先升到 0.10.0，再在网页端插入嵌入卡片。** 反过来（网页端已经插入、桌面端仍是 0.9.0）打开那篇笔记，卡片会显示成一行源码文本。数据不会丢，桌面端升级后即恢复正常。
- 此前版本创建的嵌入卡片同步到网页端后，需要跑一次「数据管理 → 数据修复 → 嵌入卡片补线上标识」补上网页标识，网页端才会显示成卡片。
- 本版**未产出 Windows 安装包**（打包配置已就绪，尚未在 Windows 上实测）。
- 打开磁盘上的 `.md` 文件时默认进入源码模式（外部文件保真优先，应用不会自动改写原文）。
