# 心悦笔记 0.5.0

这次更新重点完善全库同步、附件管理与数据可迁移性，并统一桌面端关键弹层和内容展示体验。

## 新功能

- 新增同步中心：展示同步范围、真实变更统计、最近 20 次同步记录和连接设置。
- 新增冲突处理：支持对比本地与云端版本，并选择保留本地、采用云端或两份都保留。
- 新增附件管理中心：按类型、来源和状态筛选附件，查看引用笔记、本地占用与上传状态。
- 新增附件完整性检查与一键修复：识别缺失或损坏文件，支持云端恢复和待上传附件补传。
- 新增孤立附件一键清理：逐项安全处理，单项失败不会中断整批操作。

## 数据与导入导出

- `.xynotes` 完整备份改为 ZIP 容器，直接保存原始附件文件，不再把附件内嵌为 Base64。
- Markdown 批量导出使用 `assets` 目录保存资源，单篇 Markdown 导出保留原始引用，不再转换 Base64。
- 不再兼容旧 JSON 格式 `.xynotes`，并提供旧 Base64 正文迁移为本地附件的脚本。
- 任意 HTTP(S) 站点资源均可离线缓存，并在附件管理中区分笔记附件与外链缓存。

## 体验改进

- 正文图片右键菜单支持复制实际 Markdown 图片地址。
- 附件卡片统一使用紧凑标签展示大小、来源、上传状态与引用数量；操作按钮固定在卡片右侧。
- 同步中心和附件管理统一图标、字号、按钮密度、深色模式及窄窗口布局。
- 优化弹层视口边界、代码语言菜单、搜索输入框和代码块选区对比度。

## 下载说明

- macOS ARM64 可直接使用免安装版 `心悦笔记.app`。
- 当前版本未进行 Apple Developer 签名和公证；首次打开如被系统拦截，请前往“系统设置 → 隐私与安全性”允许打开。
