# 心悦笔记 0.8.0

这次把「笔记之间的连接」做完整了：可以把一篇笔记**嵌入**到另一篇的正文里，而且链接和嵌入会**统一**计入引用关系；侧栏的「关系」面板重做为双向列表 + 图谱，点开都是新标签页，不打断当前阅读。

## 笔记嵌入

- 正文中可嵌入另一篇笔记，显示为卡片：标题、所在文件夹、更新时间、正文摘要。
- 卡片可展开查看全文；点卡片主体展开/收起，点右侧箭头在新标签页打开对应笔记。
- 卡片支持右键菜单：打开笔记、复制链接、移除嵌入。
- 三个插入入口：编辑器工具栏按钮、`/` 斜杠菜单「嵌入笔记」、正文右键菜单。
- 被嵌入的笔记被删除或找不到时，卡片显示兜底提示，不会留下空白块。

## 连接与引用关系

- **链接和嵌入现在统一计入引用关系**。此前只有链接会被统计，嵌入卡片完全不进关系表，导致侧栏关系面板和关系图谱都漏掉嵌入的连接 —— 本次修复后两者口径一致。
- 侧栏新增「关系」页签，分「引用了本篇」和「本篇引用」两个方向，空分组不显示。
- 「关系」下可切换「列表 / 图谱」两种视图，各自独占全高。
- 点击关系列表或图谱中的笔记，均以**新标签页**打开，保留当前笔记的阅读位置。
- 移除「提及」功能：它依赖标题字符串匹配，噪音较大，收益有限。

## 链接跨端可用

- 插入笔记链接时优先落库**线上真实地址**，网页端可直接点击打开。
- 尚未同步到云端的笔记退回本地地址兜底，同步后再自动转为线上地址。

## 同步与数据一致性

- 在网页端新增或删除链接、嵌入卡片后，桌面端**同步完成即会重建关系**，不再需要先在本地编辑一次才刷新。
- 冲突解决（保留本地版本）、Markdown 导入、备份恢复等改写正文的路径，都会同步重建引用关系。
- 升级后首次启动会按新的解析规则自动重建一次历史关系（笔记量较大时首次启动会略慢一两秒）。

## 关系图谱

- 新增**全库双链关系图谱**，标题栏入口打开，一眼看到整个笔记库的连接结构。
- 只纳入至少参与一条关系的未删除笔记，并按连接度裁剪数量上限，避免大笔记库下布局卡顿。
- 移除侧栏重复的「全局知识图谱」文字按钮，入口统一。

## 体验与设置

- 设置中可选择左侧笔记列表排序：最近更新 / 创建时间 / 标题（置顶笔记始终优先）。
- 菜单栏新增「开发者」菜单：打开开发者工具、重新加载主窗口，便于排查界面问题。
- 嵌入卡片嵌在另一张卡片里时，占位提示更紧凑，不再占据整块高度。

## 稳定性与工程

- 修复 AI 助手同步状态经 IPC 传递时的克隆报错。
- 更新安装包文件名补充 macos 平台标识，避免与其他平台产物混淆。
- 后台 Electron 端到端测试恢复可运行，13 个用例全部通过；单元测试 220 项通过。

## 已知限制

- 嵌入卡片同步到网页端后，阅读页显示为空块、编辑态显示为一段源码文本。数据会完整保留、不会丢失，桌面端不受影响；网页端暂不支持渲染卡片。

## 下载说明

- macOS ARM64 可直接使用免安装版 `心悦笔记.app`。
- 当前版本未进行 Apple Developer 签名和公证；首次打开如被系统拦截，请前往「系统设置 → 隐私与安全性」允许打开。
