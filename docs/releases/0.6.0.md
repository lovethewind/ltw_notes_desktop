# 心悦笔记 0.6.0

这次更新重点完善桌面端多笔记工作流、本地性能和同步稳定性，并收敛编辑器与弹层的一致体验。

## 工作区与批量管理

- 标签页会话保存在本地 SQLite：恢复打开顺序、活动笔记、固定状态和阅读位置。
- 固定标签不会被普通打开或“关闭其他标签”误关闭，并支持固定组、普通组内独立拖动排序。
- 保留原文件夹树进入多选模式，批量移动、添加/移除标签、置顶、恢复和永久删除统一收进右键菜单。
- 关闭全部标签后重启或自动同步仍保持空白；macOS 红色关窗会先保存草稿与会话。

## 搜索与性能

- 快速打开新增文件夹、标签、更新时间和仅置顶组合筛选，支持空关键词筛选、单项清除及最近搜索管理。
- 结构化条件在 SQLite 截断结果前执行，大笔记库不会因候选上限漏掉有效结果。
- 工作区列表只加载标题、元数据和本地摘要；正文、历史详情和冲突版本按需读取。
- 编辑器、快速打开、历史记录和通用设置改为按需加载，缩小启动首包。

## 稳定性修复

- 撤销与重做历史按笔记隔离，避免切换笔记后撤销出上一篇正文，并按真实可用状态置灰按钮。
- 同步删除当前笔记后自动切换到下一篇可用笔记，不再重新加载回收站正文。
- 冲突处理在启用覆盖操作前加载两侧完整正文，避免基于截断摘要作出选择。
- 空正文历史版本可正常显示，不再一直停留在加载状态。
- 修复关闭最后标签后立即关窗仍恢复旧笔记、文件夹默认全部展开及空状态深色按钮等问题。

## 工程结构

- 更新、附件、备份、快速打开、历史和通用设置按功能模块拆分。
- Electron IPC、数据库 schema、全文搜索和退出保存协调器从主入口拆出，并增加后台 Electron E2E 回归。

## 下载说明

- macOS ARM64 可直接使用免安装版 `心悦笔记.app`。
- 当前版本未进行 Apple Developer 签名和公证；首次打开如被系统拦截，请前往“系统设置 → 隐私与安全性”允许打开。
