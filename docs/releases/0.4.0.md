# 心悦笔记 0.4.0

这次更新重点完善多笔记工作流、数据迁移体验和同步可靠性，并针对大正文场景进行了性能优化。

## 新功能

- 新增浏览器式笔记标签页：支持在新标签页打开、关闭当前、关闭其他、关闭右侧标签；标签过多时自动收进下拉列表。
- 新增复制笔记：可在复制前重命名并选择目标文件夹，默认保留在原笔记位置，同时复制正文和标签。
- 导入支持直接选择 ZIP 压缩包：读取包内 Markdown 内容，不额外创建压缩包名称对应的根文件夹。
- macOS 顶部新增“搜索”菜单，集中提供全库搜索、快速打开和当前笔记查找。

## 体验改进

- 新版本弹窗加大，并支持安全的 Markdown 发布说明渲染。
- 文件夹和标签移动到标题右侧，压缩编辑器头部和工具栏高度，为正文释放更多空间。
- 全屏弹窗统一增加右上角关闭按钮。
- 同步设置显示线上默认地址 `https://lovethewind.cn`，修改后仍可随时参考。
- 优化侧边栏和文件夹弹层的内部滚动条宽度，正文右侧主滚动条保持原宽度。
- 标签筛选没有匹配结果时，不再显示无关空文件夹。

## 性能优化

- 侧边栏摘要只处理有限长度正文，避免含 Base64 图片的大笔记导致文件夹展开卡顿。
- 文件夹笔记数量改为一次性统计，减少目录渲染中的重复计算。
- 历史记录列表只读取短摘要，选择具体版本时才加载完整正文；打开历史记录不再触发同步。

## 问题修复

- 修复清空回收站后，旧同步结果可能让已永久删除内容重新出现的问题。
- 修复同步进行期间移动文件夹、重命名或编辑笔记，旧同步快照可能覆盖本地新改动的问题。
- 修复标签筛选为零结果时仍展示全部文件夹的问题。

## 下载说明

- macOS ARM64：可下载 DMG 安装包，或直接使用免安装版 `心悦笔记.app`。
- 当前版本暂未进行 Apple Developer 签名和公证；首次打开如被系统拦截，请前往“系统设置 → 隐私与安全性”允许打开。
