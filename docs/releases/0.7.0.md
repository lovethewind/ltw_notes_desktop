# 心悦笔记 0.7.0

这次更新把笔记的“连接”与“AI 辅助”真正连起来：新增双链关系、以当前笔记为中心的局部关系图谱，并加入可回链到来源的 AI 笔记助手。

## 关系与图谱

- 编辑器内可插入指向本地笔记的内部链接，正文以 `xinyue-notes` 链接格式存在本地。
- 大纲侧栏新增“反向链接”，列出引用了当前笔记的链接与未链接提及，点击可直接跳转。
- 新增“关系图谱”：以当前笔记为中心，双向展开 1/2/3 跳引用网络，支持深度切换、点击节点跳转和空态提示。
- 图谱按深度环形分层布局，中心笔记固定在画布中心，标题过长自动截断，侧栏宽度变化时自动重排。
- 补全浮层贴近窗口底部时不再被裁切。

## AI 笔记助手

- 顶部新增全局入口，随时开关右侧 AI 助手面板。
- 支持“当前笔记 / 当前文件夹 / 全部笔记”三种检索范围，按范围召回候选笔记。
- 使用 SQLite FTS5 召回候选，仅把有限文本片段发送给 OpenAI 兼容接口，不传输整库正文或附件。
- 回答附带结构化来源卡片，点击可打开对应笔记；回答以 Markdown 渲染并做安全净化。
- API Key 用系统安全存储加密后保存在本机配置文件，不进入 SQLite、同步或备份。

## 稳定性与工程

- AI 设置通过 IPC 传递前显式剥离响应式对象，保存后不再出现克隆错误。
- AI 助手、关系图谱、双链均有单测与后台 Electron E2E 覆盖。

## 下载说明

- macOS ARM64 可直接使用免安装版 `心悦笔记.app`。
- 当前版本未进行 Apple Developer 签名和公证；首次打开如被系统拦截，请前往“系统设置 → 隐私与安全性”允许打开。
